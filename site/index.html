Thesis 0.1.7 — exact courses-folder selection

Choose Workspace Folder now uses the exact folder you select. It no longer adds another courses folder or copies a template into your selected location. Cache, update downloads and settings stay in Thesis's application-data directory.

Existing workspace selections keep their previous course location on upgrade. After installing this update, choose the folder that directly contains your course folders, then close and reopen Thesis. Selecting a folder does not move, replace or delete your existing files. Extra folders created by earlier versions are left untouched.

Also protects existing course directories when duplicate creation requests arrive together. Automated tests cover retained files, legacy settings, exact folder selection and restart.

Use Application → Check for Updates, then save your work and Restart to Update. Alternatively, close Thesis and run the installer over your current installation; no uninstall is needed.

Windows x64 pilot. The update manifest is signed; the installer is not yet Authenticode-signed. Installed update/rollback and Bayer laptop qualification remain separate release gates.

Close Thesis before installing. Existing users with site updates enabled can use Application → Check for Updates.
