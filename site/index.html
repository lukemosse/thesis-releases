Thesis 0.1.3 — update-enabled Windows pilot

- Enables signed update checks from https://thesisreleases.netlify.app/.
- Downloads verified update packages from GitHub Releases.
- Includes the preview browser-launch and non-AI SCORM publishing fixes.

Close Thesis and run ThesisSetup-0.1.3.exe as your normal Windows user. Versions
0.1.2 and earlier need this manual installation to enable future site updates.
Use Application → Check for Updates, then save and choose Restart to Update when
a newer version is ready.

This is a pilot installer without Windows Authenticode signing. Update manifests
are signed independently. Managed Bayer laptop and installed version-to-version
upgrade testing remain outstanding. AI authoring and advanced media workflows
are not included in this pilot.

Close Thesis before installing. Existing users with site updates enabled can use Application → Check for Updates.
