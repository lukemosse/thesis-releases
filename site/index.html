Thesis 0.1.6 — desktop authoring workflows

Adds the remaining web-editor workflows to the Windows desktop host:
- Project management, visual media, narration management, backgrounds and component audits.
- Authoring AI, copy editing, discussions and AI answer keys through the existing Anthropic integration.
- Review/test ZIPs and complete handover assembly, including testing documents and portable course source.
- Storyboard/review-document windows with PDF export.
- Export Current Course Backup, preserving course assets, discussions, review history and narration state.
- Correct model, HDR, audio and document asset-picker categories.

Open Application → Connections to configure Anthropic, Synthesia and an installed ffmpeg.exe. Keys are encrypted for your Windows account, remain outside course data, and are never shipped in installers or published courses. Live services require your approved accounts. No live provider requests were used during automated verification.

From 0.1.5, use Application → Check for Updates, save your work, then Restart to Update. Older versions with silent update checks can be updated by closing Thesis and running this installer over the existing installation. No uninstall is needed.

Windows x64 pilot. The update manifest is signed; the installer is not yet Authenticode-signed. Bayer laptop qualification, corporate identity/network integration and installed update/rollback validation remain separate release gates. Video-production pipeline development remains outside the desktop authoring application.

Close Thesis before installing. Existing users with site updates enabled can use Application → Check for Updates.
