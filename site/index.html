Thesis 0.1.4 — updater test

- Adds “Update test release: 0.1.4” to Help → About Thesis.
- Clarifies that the first installer-launched session must be closed and Thesis
  reopened from the Start menu before checking for updates.

To test the updater from 0.1.3: choose Application → Check for Updates, wait until
0.1.4 is ready, save any work, then choose Application → Restart to Update.
After reopening, check Help → About Thesis for version 0.1.4 and the test marker.
Open an existing course to confirm your workspace is retained.

This remains a Windows pilot without Authenticode signing. Update manifests are
Ed25519-signed and packages are hash-verified. No course format or content changes
are included in this release.

Close Thesis before installing. Existing users with site updates enabled can use Application → Check for Updates.
