Thesis 0.1.5 — update progress and connection feedback

Check for Updates now opens a status window immediately, including when a background check is already running. Downloads show progress and can continue while you work. Connection failures are visible and can be retried. Slow downloads have a longer time limit; stalled transfers stop with an explanatory error.

Save your work before using Application → Restart to Update. If 0.1.3 or 0.1.4 cannot complete its update, close Thesis and run this installer, then reopen it from the Start menu. There is no need to uninstall or delete your workspace.

Windows x64 desktop pilot. The update manifest is cryptographically signed; the Windows installer is not yet Authenticode-signed. Native in-place updating remains under pilot validation.

Close Thesis before installing. Existing users with site updates enabled can use Application → Check for Updates.
